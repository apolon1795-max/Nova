# Новатория — тест «На какого предпринимателя ты похож»

Мини-приложение для детей и подростков 7–17 лет. Ребёнок отвечает на 10 вопросов, получает игровой предпринимательский профиль, три сильные стороны и небольшой практический эксперимент.

## Пользовательский сценарий

1. Ребёнок проходит 10 вопросов с обращением на «ты».
2. Приложение показывает наиболее близкий из восьми предпринимательских профилей.
3. Ребёнок вводит телефон мамы или папы и подтверждает разрешение взрослого.
4. Результат и контакт сохраняются в YDB; после добавления двух секретов Новатория получает уведомление в Telegram.
5. Только после подтверждённого сохранения появляется карточка результата, которую удобно заскринить, скачать в PNG или отправить как скопированный текст.

Автоматического сообщения родителю нет: ребёнок делится результатом самостоятельно любым удобным способом.

## Что реализовано

- адаптивный интерфейс в фирменной стилистике Новатории;
- корректное склонение имён на экране результата;
- предупреждение, что тест игровой и не является оценкой личности или выбором профессии;
- обязательное согласие перед отправкой телефона;
- проверка телефона, honeypot, минимальное время заполнения и ограничение размера запроса;
- идемпотентное сохранение: повторный запрос с тем же `leadId` не создаёт второй лид;
- таблица `novatoria_quiz_leads` в YDB как источник истины;
- готовое Telegram-уведомление после сохранения; в созданной функции остаётся добавить токен бота и ID чата;
- успех в интерфейсе только после ответа сервера `stored: true`;
- UTM-метки, URL страницы и реферер в записи лида;
- карточка 1080×1350 PNG без внешних зависимостей;
- локальные оптимизированные портреты вместо нестабильной загрузки с фотохостинга;
- автоматическая проверка всех 9 765 625 комбинаций ответов;
- 15 автоматических серверных тестов и TypeScript-проверки.

## Локальный запуск

Нужен Node.js 22 или новее.

```bash
npm install
npm --prefix backend/yandex-function install
```

В первом терминале:

```bash
npm run backend:dev
```

Во втором:

```bash
npm run dev
```

Локальный Vite-сервер передаёт `/api/lead` тестовому серверу на `127.0.0.1:8787`. Тестовый сервер хранит записи только в памяти и не отправляет реальные уведомления.

Полная проверка:

```bash
npm run verify
npm audit
```

## Производственная схема

Основная ссылка для детей остаётся прежней: [https://nova-pi-eosin.vercel.app](https://nova-pi-eosin.vercel.app).

```text
Vercel — прежний публичный адрес
          ↓ /api/lead
Vercel Function — защищённый прокси
          ↓ HTTPS
Yandex Cloud Function
     ├─→ YDB — реестр лидов
     └─→ Telegram — уведомление
```

Резервная статическая копия размещается в Yandex Object Storage и обращается к той же функции напрямую. Подробная инструкция: [docs/DEPLOYMENT_YANDEX_CLOUD.md](docs/DEPLOYMENT_YANDEX_CLOUD.md). Фактическое состояние созданных ресурсов и проверок: [docs/PRODUCTION_STATE.md](docs/PRODUCTION_STATE.md).

Совместимость с текущим Vercel-проектом сохранена через `api/lead.js`. Бесплатный Vercel Hobby официально предназначен только для личного некоммерческого использования. Поэтому нулевую стоимость прежней Vercel-ссылки для коммерческого запуска можно подтверждать только после проверки тарифа аккаунта: [Vercel Fair Use Guidelines](https://vercel.com/docs/limits/fair-use-guidelines).

## Важно про стоимость и персональные данные

Схема рассчитана на малый трафик и бесплатные месячные объёмы Yandex Cloud. Это не безусловная гарантия нулевого счёта: после превышения бесплатных объёмов применяется обычная тарификация, а для работы облака нужен платёжный аккаунт. Актуальные условия: [Yandex Cloud free tier](https://yandex.cloud/ru/docs/billing/concepts/serverless-free-tier) и [Object Storage pricing](https://yandex.cloud/ru/docs/storage/pricing).

В интерфейс встроена текущая публичная ссылка Новатории на политику обработки данных. Техническая реализация не заменяет юридическое согласование формулировок, сроков хранения и круга сотрудников с доступом к телефону родителя.

Статус и происхождение графических материалов описаны в [docs/ASSETS.md](docs/ASSETS.md). В репозитории нет документов, подтверждающих право коммерческого использования портретов предпринимателей; до передачи компании их нужно подтвердить или заменить.
